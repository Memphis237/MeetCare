# POWERPOINT SPRINT 2 - VERSION RÉDUITE

## Slide 1 - Titre
**MeetCare - Sprint 2**  
Application de gestion médicale en Java / JavaFX  
Équipe : [à compléter]

## Slide 2 - Rappel du projet
**MeetCare** est une application de bureau qui permet :
- de rechercher un médecin ;
- de prendre rendez-vous ;
- de gérer les documents et factures ;
- de connecter patients, médecins et administrateurs sur une même plateforme.

## Slide 3 - Objectifs du Sprint 2
Pendant ce sprint, nous voulions :
- rendre l’espace patient fonctionnel ;
- développer l’espace médecin ;
- développer l’espace administrateur ;
- relier davantage l’application à la base de données ;
- ajouter la messagerie, les disponibilités, les documents et la facturation.

## Slide 4 - Réalisations principales
Ce qui a été ajouté pendant le Sprint 2 :
- dashboard patient dynamique ;
- agenda et disponibilités médecin ;
- gestion des patients côté médecin ;
- documents médicaux ;
- facturation ;
- messagerie et assistant IA ;
- dashboard et supervision administrateur.

## Slide 5 - Démonstration métier
Exemple de scénario :
1. le médecin ouvre ses disponibilités ;
2. le patient recherche un médecin ;
3. il réserve un créneau ;
4. le rendez-vous apparaît côté médecin ;
5. le médecin envoie un document ;
6. le patient le retrouve dans son espace.

## Slide 6 - Architecture et base de données
Évolutions techniques du sprint :
- enrichissement du schéma SQL ;
- ajout des disponibilités ;
- ajout des messages et participants ;
- ajout des documents et factures ;
- structuration DAO / contrôleurs / interfaces ;
- meilleure gestion des rôles utilisateur.

## Slide 7 - Difficultés et solutions
Difficultés :
- nombreuses pages à relier ;
- conflits Git ;
- erreurs de compilation après fusion ;
- cohérence visuelle entre les espaces.

Solutions :
- fusion et nettoyage des branches ;
- harmonisation des sidebars ;
- recompilation propre ;
- sécurisation de plusieurs contrôleurs.
